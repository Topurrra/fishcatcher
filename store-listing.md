## Summary (short description, ≤132 chars)
Warns you about phishing-like URLs in plain language — typos, look-alike characters, fake login pages. Never blocks.

## Description (EN)
FishCatcher watches the address of every page you visit and explains, in plain
language, when something looks like a phishing trick:

- misspelled brand domains (micr0soft.com, paypa1.com)
- look-alike characters from other alphabets (pаypal.com)
- fake login pages hiding behind long subdomain chains
- raw IP addresses and other classic tricks

Instead of a scary binary verdict, you get a clear risk level (low / elevated /
high / critical) and the exact reasons behind it — so you learn to spot these
tricks yourself.

FishCatcher never blocks, redirects, or modifies pages. An optional strict
mode (off by default) can show a dismissible warning banner on risky pages.

Privacy by design: analysis happens entirely on your device. No accounts, no
analytics, no data leaving your browser. Open source (MIT) — the privacy
promise is verifiable by reading the code. English and Georgian included.

This tool uses transparent URL pattern analysis. No tool can guarantee a site
is safe — always stay alert when entering passwords.
